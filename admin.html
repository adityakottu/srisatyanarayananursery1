Publish & Share

Bake all your current data into a self-contained HTML file that anyone can open — no setup needed.

ⓘ Why others see an empty site

  • All plant edits, gallery images, visitors, logo and hero photo are stored in your browser's localStorage
  • When you share the HTML file, the recipient gets the code — but not your data
  • Publish solves this by embedding your current data directly into the HTML file

📤 How Publish Works

Publish creates a small launcher file (~100KB) that bakes all your current data into it. When anyone opens the launcher file, it automatically seeds the website with your data and opens it. All three original files + the launcher must be in the same folder.

What gets baked in

📤 Website Launcher

Download SSN-Website-Launcher.html and put it in the same folder as the website file. Share that folder. Visitors open the launcher → data loads → website opens.

Tap the link below to download:

⬇ SSN-Website-Launcher.html

📤 VIP Portal Launcher

Download SSN-VIP-Launcher.html for private clients. They open the launcher → loads VIP collection → ready to browse.

✓ Launcher downloaded!

To share: Put the launcher file in the same folder as the 3 HTML files → zip the entire folder → share the zip.
Recipients: Unzip → open SSN-Website-Launcher.html first → website opens automatically with all your content.

💡 Tips for Sharing

1
Always use Publish (above) to generate the shareable file — don't share the original admin file directly
2
The three files (Website, Admin, VIP) must stay in the same folder to link to each other
3
For fastest loading: host on a web server (GitHub Pages, Netlify — both free). Ask your developer to help upload these files
4
After making changes in Admin, run Publish again to refresh the shareable copy
