WHAT WAS CAUSING "Uncaught Error: Script error."

Six <img> tags had src="" (an empty value). A browser treats that as
"fetch the current page as an image", which always fails. Some browsers
report that failure as an opaque "Script error." with no detail.

Those placeholders now carry no src attribute at all. The page sets a
real one when a photo exists, and leaves the tag empty when it does not.
