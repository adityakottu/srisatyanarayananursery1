UPLOADING TO GITHUB

FIRST TIME
  1  github.com/adityakottu/srisatyanarayananursery1
  2  Add file > Upload files
  3  Select EVERYTHING inside this folder (Ctrl+A / Cmd+A) and drag
     the CONTENTS onto the page — not the folder itself
  4  Commit changes

THEN SET UP ONE-CLICK PUBLISHING (once)
  1  github.com/settings/tokens > Fine-grained tokens > Generate new
  2  Repository access: Only select repositories > srisatyanarayananursery1
  3  Repository permissions > Contents: Read and write
  4  Copy the token
  5  Admin > Import & Export > Connection settings > paste > Save & Connect

  From then on, just press "Publish Now" after making changes.
  Your photos appear on every device within a minute.
